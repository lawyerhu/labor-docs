# 首发版本范围与验收边界

## 面向用户

首发服务劳动者和用人单位，处理中国大陆劳动争议文书整理。首发阶段只覆盖：

- 劳动仲裁：仲裁申请书、证据目录、证据材料。
- 仲裁后起诉：要素式民事起诉状、普通式民事起诉状、证据目录、证据材料。

## 首发规则

- 用户至少选择案件阶段和申请人/原告一方后，允许生成正式格式稿。
- 缺失信息使用`[待填入：...]`，事实冲突使用`[待核实：...]`，未核验法律依据使用`[待核验法律依据]`。
- 不生成虚构的证据目录项目、证据页码、金额或法律条文。
- 无实际证据时生成只有表头的横向四列证据目录 DOCX，不生成空白证据材料PDF。
- 有实际证据时，证据材料从第一页连续编号，页脚为`第X/N页`，目录页码和PDF书签一致。

## 首发明确不包含

- 答辩状、上诉状、强制执行申请书。
- 在线支付、电子签名、直接向法院提交。
- 律师人工审核和案件结果承诺。

## 发布闸门

满足以下条件才进入封闭内测：

1. 标准案件库40个全部通过。
2. 四条主路径均能完成创建、补充、上传、生成和下载。
3. 文书、金额、证据目录和证据PDF的回归测试通过。
4. 越权访问、文件上传、提示词注入、限流和到期删除测试通过。
